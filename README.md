# Hukuk Bürosu Otomasyonu — Kurulum Paketleri

Bu repo yalnızca kurulum paketlerini (`HukukBurosuOtomasyonu-Kurulum-<sürüm>.exe` ve `.sha256`) barındırır. Kurulu sistemler yeni sürümü buradan günde bir kez denetler ve kendiliğinden kurar.

Kurulum için **Releases** bölümündeki son sürümü indirip yönetici olarak çalıştırın.
